# crypto-lab-saml-binding

Baseline only. Nothing is implemented yet.

This repository is being created to hold a browser-based teaching lab about
SAML 2.0 assertion handling and the gap between verifying an XML signature and
authorizing from the object that signature actually covered.

No lesson, no demo page and no security claim exists here yet. The implementation
and its design/source record arrive on a pull request.

*Part of the [Crypto Lab](https://crypto-lab.systemslibrarian.dev/) suite.*
